## O PROBLEMA DO WORDPRESS (0:40–3:00)

Eu não tenho nada contra WordPress. Ele dominou o mercado por anos e tem razão de existir.

Mas tem um problema sério quando você está construindo estrutura para ranqueamento, velocidade e IA.

WordPress é pesado por padrão.

Você instala, já vem com código desnecessário. Aí instala plugin, mais código. Plugin de SEO, mais código. Plugin de cache, mais código. Plugin de segurança, mais código.

No final você tem um site que demora 4 segundos pra abrir no celular.

E o Google usa velocidade como fator de ranqueamento. O Core Web Vitals — que é a métrica oficial de velocidade do Google — pune sites lentos.

Isso sem contar os problemas de segurança. WordPress é o CMS mais atacado do mundo. Plugin desatualizado vira porta de entrada pra invasão.

E a pior parte: todo mundo usa. Seu cliente tem um WordPress. A concorrência do seu cliente tem um WordPress. Você entregando WordPress não é diferencial, é padrão.

## POR QUE NEXT.JS (3:00–6:30)

Next.js é um framework React. Desenvolvido pela Vercel — a mesma empresa que hospeda os sites mais rápidos do mundo.

Por que isso importa pra você?

**Velocidade nativa.**
Um site Next.js bem construído carrega em menos de 1 segundo. Isso não é exagero — é o que acontece quando o código é limpo e você não tem 40 plugins carregando junto.

Google ama. ChatGPT consegue ler melhor. Usuário fica.

**Geração estática.**
Next.js gera as páginas como HTML puro quando você faz o deploy. O servidor não precisa processar nada quando o usuário acessa — a página já está pronta. Isso é absurdamente rápido.

**Indexação perfeita.**
O HTML gerado é limpo, semântico, fácil pra qualquer crawler — Google, Bing, GPTBot — ler e entender. Isso é fundamental pro GEO que a gente vai ver na aula 4.

**Escalável sem custo.**
Hospedado na Vercel, o site aguenta pico de tráfego sem você pagar mais. Pequena empresa com campanha rodando? Sem problema.

**E o mais importante pra você:** você não precisa saber programar pra usar Next.js.

Com Claude Code — que é a IA da Anthropic — você descreve o que quer e o código é gerado. Você revisa, ajusta, publica. É o que eu uso todo dia com cliente real.

## A STACK COMPLETA (6:30–9:00)

Quando eu falo de stack certa, são quatro elementos:

**1. Next.js** — o framework. É onde o site vive.

**2. Vercel** — a hospedagem. Gratuita pra começar, integra com GitHub, deploy automático em segundos. Quando você faz uma mudança, o site atualiza sozinho.

**3. GitHub** — onde fica o código. Versionamento — se algo der errado, você volta pra versão anterior. E é de onde a Vercel puxa pra fazer o deploy.

**4. Domínio próprio** — .com.br ou .com. Registro.br pra domínio brasileiro, Namecheap se quiser .com. Sem domínio próprio, seu site aparece como `seunome.vercel.app`. Não passa profissionalismo.

Esses quatro elementos custam praticamente zero pra começar. Domínio sai R$40 por ano. Vercel é grátis pra projetos pequenos. GitHub é grátis. Next.js é open source.

Você entrega um site de R$7.000 com infraestrutura que custa R$40 por ano.

Sim. Se o cliente já tem WordPress com muito conteúdo, equipe que sabe usar, não faz sentido mudar tudo.

E o diferencial de você saber isso vai aparecer na hora que o cliente perguntar: "Qual é a diferença do que você faz pra qualquer agência?"

A resposta é essa: eu construo com a mesma tecnologia que os sites mais rápidos do mundo usam. Não com o que todo mundo usa.
